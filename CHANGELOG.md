# Changelog

## 0.1.0

- Initial release.
- Taddy Podcast API node: Podcast, Episode, Search, Chart, Webhook, Account and GraphQL resources (one operation per Taddy MCP tool).
- Taddy Podcast API Trigger node: registers a Taddy webhook on activation and verifies the `X-TADDY-WEBHOOK-SECRET` header.
- Taddy Podcast API credential (`X-USER-ID` / `X-API-KEY`).
